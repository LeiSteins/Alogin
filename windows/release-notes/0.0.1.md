- 首次发布 Windows 10/11 x64 原生客户端，提供校园网认证、网络状态、在线账号流量与余额查询及在线设备下线。
- 支持多账号管理，密码使用当前 Windows 用户的 DPAPI 加密保存。
- 支持目标 Wi-Fi 配置、自动登录与掉线重登，可调整检测及重试间隔；密码错误时暂停自动提交，主动下线本机后可暂停自动重登。
- 支持系统托盘、单实例、关闭窗口后后台运行，以及可选的登录 Windows 后启动到托盘。
- 支持浅色、深色、跟随系统和高对比度外观，自适应卡片布局与可收起侧栏。
- 本版提供便携 ZIP 包，解压后运行 alogin-windows.exe；更新时从托盘正常退出，再覆盖程序文件，账号和设置保留在 %LOCALAPPDATA%\Alogin\。
- 当前未提供 Windows 代码签名、客户端自动更新、无感知绑定管理或附近 Wi-Fi 扫描。
